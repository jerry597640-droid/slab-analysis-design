# 樓板分析設計

繁體中文互動樓板分析工具，依 Slab_20121009_SourceCode 的 USD 公式移植，新增板自重自動計算。

## 使用

開啟 index.html 即可使用，無需安裝套件。亦可使用 GitHub Pages。

- 修改幾何、材料、邊界及載重，即時更新分析。
- 額外靜載重 D 不含樓板自重。
- 樓板自重 = h(cm) / 100 × 2.4 tf/m³。
- 總靜載重 = 板自重 + 額外 D。
- wu = 1.2 × 總靜載重 + 1.6 × 活載重。
- 提供六處配筋檢核、詳細公式、規範核對及可編輯 Word 計算書匯出。

## 工作台介面

桌面採固定工具列、左側參數與右側分析面板；手機採設計參數／分析結果／計算報告底部導覽，配筋表改為逐位置卡片，輸入控制至少 44px，数值欄位支援小數鍵盤。

## 驗證

2026-10-02：54 組案例通過自重、載重及彎矩數值檢查；以獨立二分法解斷面彎矩平衡，與原碼配筋反算結果一致。另驗證 20cm 自重、Word 代入、兩組重力載重包絡、錯誤輸入、分頁及手機導覽。

官方核對：https://www.nlma.gov.tw/filesys/file/EMMA/c1130219-1.pdf

現行規範尚須修正或補算：剪力折減因數、Vc 公式、有效深度、拉力控制、係數法適用性、雙向板厚及沖切等。原始係數表之規範出處未能確認，因此不宣稱完整規範符合。
